# Campus Lost & Found - Web Management System

A full-stack campus portal designed to help university students and faculty report, search, and recover misplaced belongings through an intuitive digital registry.

## 🚀 Key Features
- **Dynamic Item Catalog:** Searchable and filterable registry categorizing lost vs. found items.
- **Claim & Report Submissions:** Clean interface for submitting item details, locations, and recovery status.
- **Full-Stack Architecture:** Decoupled architecture pairing a responsive frontend client with a robust backend service.
- **Container-Ready:** Includes Docker configuration for standardized local development and deployment.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Java, Maven, Spring Boot
- **DevOps / Config:** Docker, Render
- **Version Control:** Git & GitHub
